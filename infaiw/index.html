[ agent harness · daemon-first ]

Delegate the work. Keep the wheel.

infaiw is an agent harness that works with you, not around you. It runs as a background service: hand off a task, close the terminal, and come back to a durable timeline of everything it did, with every consequential step waiting for your approval.

[ 01 / the sidecar loop ]

Subagents that can't
just declare victory.

Agents love to say "done". A sidecar loop is a delegated subagent that isn't finished until an acceptance check agrees, and it leaves a full record behind.

1

Delegate

The parent session hands off a task together with an AcceptanceCheck: what "done" has to look like.

2

Verify

The sidecar keeps iterating until the check passes, or stops at its iteration limit and says so.

3

Record

Results come back over ISAC, and every step stays on the durable timeline for you to inspect.

A real session: one parent reviewing a change through six sidecar loops, three of them paused on approvals.

[ 03 / on board ]

Built for long-running work.

W-01

Timeline sessions

Every session is an event timeline: compact to store, fast to replay. Branch from any point and move between timelines.

W-02

Daemon, not a window

infaiw runs as a background service. Close the terminal mid-task and the work continues. Several clients can attach to the same session.

W-03

sidecar_loop

Subagents, grown up. Each delegated task carries an AcceptanceCheck, so a sidecar can't just declare victory, and every loop is recorded on the timeline.

W-04

ISAC

Inter-session agent comms, modelled on actors: every session has a mailbox and the engine routes messages between sessions. Simple wiring, no special cases.

W-05

Checklists with intent

Each task carries a short note on what was actually expected. If the agent loses the thread, it recovers the goal from the checklist: infaiw's first memory.

W-06

Hybrid auto-compaction

The latest events stay verbatim; older ones are compressed. The agent keeps sight of what it just did and resumes mid-task. Informed by DeepSeek's approach.

W-07

Human first

Approvals wait for you, even if you closed the window hours ago. Allow, deny, or deny with a reason. One simple mental model.

W-08

One system prompt

No per-model prompt hacks. Agents, like people, follow clear instructions, so one well-written prompt works across models.

W-09

Beyond text

Attach images as input, and capture model-generated images in the session, saved straight from the TUI.

W-10

MCP, skills & evals

MCP servers with OAuth, elicitation and prompts. Reusable skills. Evals to check the agent does what you asked.

W-11

Guarded web tools

Web fetch and web search, with safeguards built in.

W-12

Your choice of model

DeepSeek and OpenAI Codex today, with configurable thinking levels and provider catalogs that refresh hourly.
